想让男朋友看到你记的账，需要把记录存进你的 GitHub 仓库（和网页同一个仓库）。
① 建好放网页的仓库（Public）
② 创建一个只对这个仓库有效的“令牌 Token”
③ 在下面填 用户名 / 仓库名 / 令牌 —— 令牌只保存在你这台设备，用于写入 data.json

阅读方（男朋友）不需要填任何东西：打开网址后网页会自动读取仓库里的 data.json。
令牌是 GitHub 的“钥匙”，请只粘贴在这台你信任的设备上，别发给别人、别写进网页文件。
